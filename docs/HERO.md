# Hero

Escena 100 % CSS (cielo de atardecer, sol sobre el horizonte del logotipo). No hay fotografía: las fotos las aporta el responsable a mano.

Para sumar una foto propia (con autorización escrita, ver `CLAUDE.md` regla 6): copiarla a `images/`, optimizada, y definir en `scripts/estilos.css`, regla `.hero`, `--hero-img:url(images/ARCHIVO.jpg)` en lugar de `none`. Los degradados de la regla ya oscurecen el lado izquierdo para el texto. Revisar contraste y recortes a 1440, 768 y 390 px.
